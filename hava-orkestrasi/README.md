# Hava Orkestrası 🖐️🎶

Kameraya el hareketleriyle müzik yapma uygulaması. Telefonda ve bilgisayarda tarayıcıda çalışır. El takibi cihazın içinde yapılır (MediaPipe), görüntü hiçbir yere gönderilmez.

- **Akor + Melodi:** sol elin parmaklarını başparmağa değdirerek 4 akor; sağ el yüksekliğiyle nota seç, işaret parmağıyla çal.
- **🎸 Teller:** başparmak + işaret parmağını birleştir, çek, bırak: havada tel oluşur. Parmağını üzerinden geçirince geçtiğin tüm teller çalar. Uzun tel kalın, kısa tel ince ses verir (gerçekçi Karplus-Strong tel sesi). Telin ucunu tutup akort edebilirsin, uçları birleştirirsen tel silinir.
- **Pad:** havada parmak ucunla 16 pad'e vur (davul, akor, nota).
- **Theremin:** açık elle havada dalga gibi ses; yukarı/aşağı ince/kalın, sağ/sol parlaklık.
- 🔁 Döngü (looper): 4 vuruş sayar, 2 ölçü kaydeder, sürekli çalar, üstüne katman eklenir.
- Ritim (Pop, House, Trap, Hip-Hop, Reggaeton), arpej, ton/gam (Hicaz dahil), 5 enstrüman, video kaydı ve paylaşma.

Kamera için sayfanın **https** üzerinden açılması gerekir (ör. GitHub Pages).
